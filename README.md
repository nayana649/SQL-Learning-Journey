📊 SQL Learning Journey
Welcome to my database repository! This project is a dedicated space where I document my daily progress in SQL and Relational Database Management Systems (RDBMS).

As an Electronics and Communication Engineering student, I am building these skills to manage complex data in embedded systems, AI workflows, and full-stack applications.

🛠️ Tech Stack
Database: MySQL

Tool: MySQL Workbench

Language: SQL (Structured Query Language)

🚀 What I've Mastered So Far
1. Data Definition Language (DDL)
Creating and managing databases (CREATE DATABASE).

Designing table structures with specific data types (INT, VARCHAR, FLOAT, NUMERIC).

Cleaning up workspaces safely using DROP and TRUNCATE.

2. Data Manipulation Language (DML)
Inserting multiple records into tables (INSERT INTO).

Updating existing information with precision (UPDATE ... SET ... WHERE).

Removing specific data points using the DELETE command.

3. Transaction Control (TCL)
Understanding the "Undo" logic using ROLLBACK.

Managing permanent changes with COMMIT.

Using START TRANSACTION to ensure data integrity during complex operations.
